# Asistente de estudio verificable

Diseño aceptado en la conversación: proyecto de portfolio centrado en IA, datos y bases de datos. Aplicación local; documentos originales de demostración, sin materiales universitarios privados. El dashboard deportivo queda fuera de este repositorio.

## Primera versión

PDF con texto → extracción conservando página física → fragmentos sin cruzar páginas → embeddings locales → PostgreSQL/pgvector. Consulta mediante búsqueda léxica, vectorial o híbrida; combinación híbrida por Reciprocal Rank Fusion. Respuesta con referencias a fragmentos y enlaces a páginas. Si faltan fuentes o la salida del modelo no contiene referencias válidas, abstenerse. Esta validación comprueba la estructura de las citas, no garantiza que una afirmación sea correcta.

FastAPI sirve API y una interfaz HTML pequeña en español. Ollama se comunica por HTTP mediante un adaptador sustituible. Separamos el modelo de embeddings del generador. Las consultas vectoriales solo utilizan fragmentos del modelo de embeddings configurado. Registro de documentos por SHA-256, ingestión transaccional y serializada por documento para evitar duplicados concurrentes.

## Modelo de datos

documents (id, nombre, hash, PDF original, fecha); pages (documento, número físico, texto); chunks (página, orden, texto, modelo de embeddings, vector). El PDF se guarda en PostgreSQL para que texto, páginas y archivo compartan la misma transacción. Límite de 10 MB/100 páginas por documento en la demo. No se expone la base de datos fuera de localhost.

## Evaluación y errores

Tests de conservación de páginas, duplicados, rollback, algoritmos de búsqueda, integración HTTP y rechazo de referencias inexistentes. Evaluación de recuperación con preguntas esperadas y recall@k/MRR; las afirmaciones y citas deben revisarse también manualmente. PDFs escaneados, cifrados o inválidos producen errores claros. Servicios ausentes se muestran como no disponibles, sin datos o respuestas simuladas en la aplicación.

## Fuera de esta versión

OCR, usuarios, correo, calendario, agentes autónomos, despliegue público, entrenamiento y resumen automático. El modelo y su rendimiento se validarán en el ordenador real; no se promete latencia.

## Criterio de entrega inicial

Repositorio independiente, dos PDFs reproducibles, API/web, Compose, tests unitarios, pruebas de integración preparadas y evaluación ejecutable. Registrar explícitamente qué pudo probarse con servicios reales. Graphify y Understand Anything documentan el repositorio; no intervienen en las respuestas del RAG.
